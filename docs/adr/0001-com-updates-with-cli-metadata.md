# Use WinGet's API for updates and its CLI for missing metadata

Wingood executes concurrent updates through the installed WinGet COM API. It also reads the CLI's bulk-update listing to preserve exclusions that the API does not expose, and reformats `winget show` output because the pinned API omits useful installer details. A pure API implementation would lose those behaviors, while delegating update execution to the CLI would restore the serial download/install bottleneck. Keep text parsing isolated and validated; uncertain bulk eligibility never authorizes an update. Sean approved this decision with the complete plan on October 14, 2026. It is implemented in `v0.1.0`.
